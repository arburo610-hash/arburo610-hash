# Личный бизнес-ассистент дизайнера интерьеров

Отдельный Telegram-бот (не путать с SMM-ботом `bot.py`), который знает все ваши проекты и снимает рутину.
Опирается на уже существующую рабочую среду в Google Sheets:

- **«00 ПУЛЬТ УПРАВЛЕНИЯ ПРОЕКТАМИ»** — по строке на проект (статус, этап, ближайший срок, задачи / ожидания / блокеры).
- **«Управление проектом | ЖК …»** — таблица каждого проекта: Панель, Паспорт, Журнал, Этапы, Задачи, Решения, Открытые вопросы, Визуализатор, Чертёжник.

Таблицы уже устроены как база данных (ID записей `MOD-T-001`, `MOD-R-003`, статусы, связи), поэтому ассистенту не нужна новая система — он читает то, что вы и так ведёте.

## Карта возможностей

Что ассистент может делать для дизайнера интерьеров, по отдачам. ✅ — сделано в этой версии.

| Направление | Что делает | Откуда данные | Этап |
|---|---|---|---|
| **Проекты** | Отвечает «что по ЖК МОД?», «что ждём от заказчиков?», «какие решения по свету в Гранатах?» | Пульт + таблицы проектов | ✅ 1 |
| | Утренняя сводка пн–пт: что горит, чего ждём, фокус на день | Пульт + таблицы проектов | ✅ 1 |
| | Черновики сообщений заказчику / подрядчику по фактам из таблицы | Таблицы проектов | ✅ 1 |
| | Записать событие в Журнал, добавить задачу, закрыть вопрос — голосом или текстом из Telegram, с подтверждением | Запись в таблицы | 2 |
| | Обновлять строку Пульта (счётчики, дата обновления) по таблице проекта | Запись в Пульт | 2 |
| **Команда** | ТЗ визуализатору и чертёжнику из листов «Визуализатор» / «Чертёжник» + актуальных решений | Таблицы проектов | 2 |
| | Проверка перед выдачей: всё ли из «Что проверить перед финальной выдачей» закрыто | Таблицы проектов | 2 |
| **Комплектация** | Сборка ведомостей (отделка, электроустановка, двери) по шаблону | Шаблоны ведомостей в Drive | 3 |
| | Сверка ведомости с принятыми решениями, поиск расхождений | Ведомости + Решения | 3 |
| **Время и почта** | Встречи, выезды, замеры — в Google Календарь; напоминания за день | Google Calendar | 3 |
| | Разбор входящих писем от заказчиков/поставщиков → задачи и вопросы в таблицу проекта | Gmail | 3 |
| **Продажи** | Новый лид → анкета КП («Опросник для КП | шаблон») → черновик КП | Drive + Бизнес-модель бюро | 4 |
| | Финансы проектов: авансы, акты, что не оплачено (лист «Этапы») | Таблицы проектов | 4 |
| **SMM** | Темы для постов из реальных проектов (с согласия заказчиков) → передача в SMM-бот | Журнал + `content_plan.md` | 4 |
| **Визуал** | Описание и подписи к рендерам из 3ds Max, мудборды, подбор по референсам (по фото) | Изображения в чате | 4 |

Что сознательно **не** автоматизируем: работу в ArchiCAD / 3ds Max / Photoshop — у этих программ нет надёжного облачного доступа; ассистент работает вокруг них (ТЗ, проверки, ведомости, описания), а не внутри.

### Принципы
- **Источник правды — ваши таблицы.** Ассистент не выдумывает даты и договорённости; если в таблице нет — говорит «нет данных».
- **Запись — только с подтверждением.** Этап 1 только читает. С этапа 2 любое изменение таблицы бот сначала показывает и ждёт «Да».
- **Доступ только вам.** Бот отвечает лишь Telegram ID из `ALLOWED_TELEGRAM_IDS` — в таблицах персональные данные заказчиков.

## Запуск (этап 1)

1. **Telegram-бот.** В @BotFather создайте нового бота (отдельно от SMM-бота), сохраните токен.
2. **Google сервисный аккаунт.** В Google Cloud Console: создать проект → включить *Google Sheets API* и *Google Drive API* → *Service accounts* → создать → *Keys* → JSON. Файл положить рядом как `service_account.json` (в git он не попадёт).
3. **Открыть доступ.** Расшарить на e-mail сервисного аккаунта (`…@….iam.gserviceaccount.com`) с правами «Читатель» Пульт и все таблицы «Управление проектом | …». Проще всего — расшарить папку, где они лежат.
4. **Переменные окружения:**
   - `ASSISTANT_TELEGRAM_TOKEN` — токен из шага 1;
   - `ANTHROPIC_API_KEY` — ключ Claude API;
   - `ALLOWED_TELEGRAM_IDS` — ваш Telegram ID (бот сам подскажет его при первом сообщении);
   - `GOOGLE_SERVICE_ACCOUNT_FILE` — путь к JSON (по умолчанию `service_account.json`);
   - `BRIEF_CHAT_ID` — ваш ID, если нужна автоматическая сводка; `BRIEF_TIME` — время по Москве, по умолчанию `09:00`.
5. **Запуск:**
   ```bash
   cd assistant
   pip install -r requirements.txt
   python assistant_bot.py
   ```

Команды: `/brief` (или `/сводка`) — сводка, `/reset` (или `/сброс`) — начать разговор заново. Остальное — обычными словами.

Модель — Claude Opus 5.5 со включёнными резервными моделями на случай отказа (`fallbacks`). Если хочется дешевле — поменять `MODEL` в `assistant_bot.py` на `claude-sonnet-5-5`.

## Файлы
- `assistant_bot.py` — Telegram-бот и цикл работы с Claude (инструменты `list_projects`, `read_project`).
- `sheets.py` — чтение Пульта и таблиц проектов (кэш 2 минуты).
